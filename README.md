# LumaXMB Replica

A single-file HTML/CSS/JS replica of the LumaXMB XMB (Cross Media Bar) interface for PS Vita — recreated in the browser, no build step required.

**Live demo:** https://seasnakes.github.io/lumaxmb-replica/

## Controls

- **Arrow keys** — navigate the XMB (left/right across categories, up/down through items)
- **Enter** — select / confirm
- **Esc** — back
- **Mouse** — click items to navigate/select
- **Mouse wheel** — scroll through items
